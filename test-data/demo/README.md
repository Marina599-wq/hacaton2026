# Демо-выписки (ТЗ-доработка WP-7 §13)

Здесь лежат демо-выписки, которые грузят:

- `npm run seed` — в аккаунт `demo@cashflow.ru` (контракт: docs/api-contract.md);
- кнопка «Использовать демо-данные» (регистрация с `useDemoData`) — в аккаунт нового пользователя;
- `POST /api/demo { company? }` — подгрузка выбранной выписки в текущий аккаунт.

Файлы (CSV формата организаторов, `test-data/README.md`) выбирает `node server/scripts/pick-demo.mjs`
по правилам §13: история ≥ 18 месяцев; `gapProbabilityPct ≥ 30` на горизонте 30 дней при
`T = P10` и `asOf` = последней дате выписки; виды бизнеса разные (из `companies.csv`).

## Текущее содержимое

| Файл | Откуда |
| --- | --- |
| `statement-demo-C001.csv` | Единственная демо-выписка на сейчас (копия `test-data/C001.csv` — примера из датасета организаторов, 24 месяца; после перекалибровки вероятности по бинам бэктеста `gapProbabilityPct ≈ 2,6 %` при `T = P25`, разрыв на 2026-10-20 — `docs/BACKTEST.md`). Seed задаёт демо-учётке порог T = P25-квантиль остатков и плановые события (договор, счёт, налог, просроченный платёж) — на asOf=2026-09-29 на главной виден будущий разрыв |

Как только датасет организаторов (150 компаний / 15 видов) появится в `test-data/statements/`,
прогоните `node server/scripts/pick-demo.mjs` — он положит сюда 2–3 выписки разных видов
бизнеса с реальным разрывом (`statement-demo-<COMPANY>.csv`), и тогда обновите
`FORECAST_AS_OF` в `server/.env.example` на последнюю дату новых выписок.
